1. Plain paragraphs

Translation quality depends on context. A single sentence without context is ambiguous, but a paragraph gives the model enough information to choose the right terminology. Numbers such as 1,234.56, units like 42 km/h, dates like 2025-01-31 and prices like $19.99 should stay untouched.

Links should keep working: read the official documentation for details, or email support@example.com. Placeholders like {userName} and ${amount} must survive the round trip unchanged.

2. Lists

  • Concurrency is configurable between one and sixteen parallel requests.
  • Identical strings are de-duplicated and translated only once per page.
  • Cached translations are reused across tabs and sessions.
  1. Click the extension icon in the toolbar.
  2. Enter your own API key in the settings page.
  3. Press Translate this page and watch the progress badge.

4. Code must not be translated

function translate(items, concurrency) {
  return runPool(items, concurrency, async (item) => {
    return await callModel(item.text);
  });
}

Inline code such as Array.prototype.map stays as it is, but the surrounding sentence is translated normally.
